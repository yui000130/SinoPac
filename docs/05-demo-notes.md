# 05｜Demo 實作說明

本文件記錄 `demo/` 依照 [04-mma-kids-spec.md](04-mma-kids-spec.md) 實作時，**與規格書不同或補充的地方**。其餘一律照規格書。

## 0. 新增：初次設定（打開 Demo 第一個畫面）

1. **媽媽先設定**（DAWHO › 親子 › 初次設定）：每週零用錢、轉帳時間（星期＋時間）、配對比例、每週配對上限、這個夢想的配對上限、每月上限與單筆上限（見第 1-2 節）。每一項都有預設選項＋**自訂**（見下表）
2. **小安接著設定**（MMA Kids）：儲蓄／需要／想要三罐子比例，可選預設組合或用 ± 每次調 5%，合計必須 100% 才能按「開始使用」；畫面即時換算成每週金額
3. 設定完成後，所有數字依這組設定計算；媽媽手機上方「示範 ▾ › 重新設定」可以重來

| 家長設定 | 預設選項 | 自訂範圍 | 設定後也可在 |
|---|---|---|---|
| 每週零用錢 | $500／$800／$1,000 | $50～$5,000 | 零用錢分頁 |
| 轉帳日 | 週一～週日（七天都能選，不需自訂） | — | 零用錢分頁 |
| 轉帳時間 | 07:00／12:00／18:00 | 任意時間（00:00～23:59） | 零用錢分頁 |
| 配對比例 | 1:1／1:0.5／1:2 | 1:0.1～1:5（到小數一位） | 配對分頁 |
| 每週配對上限 | $100／$200／$300 | $10～$2,000 | 配對分頁 |
| 這個夢想的配對上限 | $300／$600／$900 | $50～$20,000 | 配對分頁 |
| 每月上限 | $1,500／$2,000／$3,000 | $100～$50,000 | 安全分頁 |
| 單筆上限 | $300／$500／$1,000 | $50～$20,000 | 安全分頁 |

按「自訂」展開輸入框，按「確定」或 Enter 套用；超出範圍或格式不對會顯示紅字提示、不會存入。套用後自訂鈕顯示目前的值（例如「自訂 $650」「自訂 1:1.5」）。初次設定以外的修改會同步到小安端（零用錢、每月上限、單筆上限會跳通知）。

## 1. 新增：日常錢包（簡化版）

| 項目 | 作法 |
|---|---|
| 首頁大圓餅圖 | 首頁最上方一個大圓餅圖，兩個頁籤：**我的錢怎麼分**（儲蓄／需要／想要的比例，中間是每週零用錢，下方列出各罐金額）、**這週花在哪**（依小安標記的需要／想要／未標記計算本週花費）。下方一句給孩子看的提示 |
| 可以用的錢 | ＝需要罐＋想要罐，顯示在圓餅圖下方 |
| 三罐子 | 儲蓄／需要／想要，預設 30% / 35% / 35%。比例在首頁圓餅圖下方「調整三罐子比例」修改（不放在錢包），下次入帳套用 |
| 儲蓄罐 | 就是夢想基金的「我存的」：零用錢的儲蓄份自動存進目前的夢想，**不產生配對** |
| 需要罐 | 交通、文具、午餐。付款時依店家類別自動扣這一罐 |
| 想要罐 | 飲料、零食、娛樂。只有花想要罐、金額 ≥ $50 時才跳出「買下去／存起來」 |
| 罐子不夠 | 會問「要用另一個罐子的錢補嗎？」，不直接擋下 |
| 分享罐 | 已拿掉 |
| 底部分頁 | 規格書的「帳本」改名為「錢包」，只放收支紀錄（可補標需要／想要）與每週回顧；需要 vs 想要的統計已移到首頁圓餅圖 |
| 任務獎勵 | 不出現在收支紀錄中（任務＝非金錢禮物，不經過帳戶） |

會配對的只有孩子主動存的錢：付款前選「存起來」、把需要／想要罐剩下的存進夢想（紅包預設不配對）。

收支紀錄分四組：今天、週一、上週、本月稍早。「本週收入／支出」與首頁「這週花在哪」只算今天＋週一；「本月已花」＝所有消費加總，與家長端「每月分類總額」一致。

## 1-2. 新增：防亂花錢設定（每月上限＋單筆上限）

取代規格書的「單日消費上限 $1,500」與「單筆 $1,000 以上要同意」，以及原本孩子自設的「每週預算」。家長在 DAWHO › 親子 › 安全（初次設定也有）調整兩個金額：

| 規則 | 預設 | 選項 |
|---|---|---|
| 每月上限 | $2,000 | $1,500／$2,000／$3,000／自訂（$100～$50,000） |
| 單筆上限 | $1,000 | $300／$500／$1,000／自訂（$50～$20,000） |

「自訂」的操作方式同第 0 節。

**超過任一個上限**（單筆金額 > 單筆上限，或本月已花＋這筆 > 每月上限）：
1. 先不付款，孩子端顯示超過了哪一個上限，可附一句話送出
2. 家長「需要你處理」收到同意請求（標題寫明超過哪個上限）
3. 家長按「同意」才付款；「不同意」或 24 小時未回覆就取消

- **錢不夠就不送同意**：掃碼時先檢查需要罐＋想要罐，不夠直接提示，不會送出一筆爸媽同意了也付不出去的請求。
- **不重複送出**：同一筆還在等爸媽回覆時，再掃一次只會提示「已經送給爸媽了」。
- **付款碼鎖住時**（小安回報可疑付款），媽媽按同意也不會扣款，會提示先處理可疑付款、解除鎖定。
- 孩子首頁有「這個月還能花」進度條（用到 80% 變紅），付款碼下方也顯示本月還能花多少與單筆上限。
- 示範：本月起始已花 $1,200（收支紀錄加總）。
  - 超過**單筆上限**＋**每月上限**：先用「示範 ▾ › 外婆轉入紅包 $2,000」補錢，再「店員掃碼：跑步鞋 $1,200」。
  - 只超過**每月上限**：媽媽把每月上限自訂為 $1,300，再掃文具店畫具組 $220。
  - 只超過**單筆上限**：媽媽把單筆上限自訂為 $200，再掃畫具組 $220。

## 1-3. 新增：可疑詐騙付款（參考 peipei628 版本改寫）

**A. 小安主動回報**：付款碼下方「可疑詐騙？通知爸媽」（付款確認頁也有「金額不對？回報可疑付款」）
1. 選狀況：陌生人要我掃碼／店員收的金額不對／網路上叫我先付款／沒買東西卻被扣款
2. 通知媽媽，**付款碼先鎖住**（鎖住時掃碼一律不付款）；孩子端顯示接下來怎麼做與 165
3. 媽媽端紅色警示：打電話給小安／通報永豐客服／確認安全，解除付款碼鎖定

**B. 卡號被盜刷（系統先擋下）**：媽媽手機上方「示範 ▾ › 卡號被盜刷：陌生海外網站 $3,000」
- 遠超過每月上限＋境外網站 → 系統擋下、**不扣款、不進收支紀錄**
- 媽媽端：「是小安本人刷的」（解除提醒，仍未扣款）或「不是，停卡通報」（卡片暫停、補發新卡；孩子首頁顯示卡片暫停，手機付款碼照常可用）
- 停卡後，媽媽總覽會有「小安的卡片暫停中」，按「新卡已收到，恢復使用」即恢復
- 依 [06-v2-review.md](06-v2-review.md) 的建議，改為「事前攔下＋家長確認」，不再是「先被刷走、事後通知」

## 1-3-2. 新增：學堂「完成課程」與防詐情境演練

**完成課程按鈕**
- 每堂課答對小測驗後出現「完成課程，回到學堂」，回到課程列表並顯示學堂進度；答對後答案鎖定。
- 還沒答對時，下方有「先回到學堂」，答錯會提示「再選一次試試看」。
- 防詐小測驗最後一題答對後為「完成測驗，回到學堂」；中途可按「先回到學堂，下次再做」，進度保留。

**防詐情境演練**（學堂 › 防詐 下方，孩子自己練習）

| 演練 | 對話 | 正確做法 |
|---|---|---|
| 人頭帳戶 | 網友說轉錯 $5,000，要你轉到他給的帳戶 | 不理他，告訴爸媽 |
| 假買家 | 二手平台買家說付款失敗，要你操作網銀「驗證帳戶」、補轉 $300 | 不轉，取消交易 |
| 付款碼 | 自稱超商店員，要你把付款碼截圖傳給他 | 不傳，按「可疑詐騙？通知爸媽」 |

- 選一個做法 → 顯示「做得好！」或「小心，這是詐騙！」、原因、真的遇到時 App 會怎麼保護你、165。
- 選錯可「再練一次」；選對按「完成演練，回到學堂」，列表標示「已完成」，媽媽的動態會看到「小安完成防詐情境演練」。
- **演練模式不會發出防詐警示、不會動到錢**。真實流程（陌生轉入、網友要求轉出、假買家、盜刷）仍在兩支手機的「示範 ▾ › 防詐情境」，會通知媽媽。

## 1-4. 新增：18 歲升級 DAWHO 辦理流程

孩子手機上方「示範 ▾ › 跳到 18 歲：升級 DAWHO」進入，同一個選單「回到 12 歲」返回。18 歲期間，家長端只剩「總覽」分頁（成年後不再管理零用錢、限額與消費）。

| 步驟 | 孩子端（MMA Kids › 升級 DAWHO） |
|---|---|
| 0 | 生日快樂、會一起帶走的東西（夢想紀錄與存款、學堂成果、信託 $50,000）、先準備：身分證、第二證件、本人手機 |
| 1 確認身分 | 身分證正反面、第二證件（健保卡）、自拍比對，三項完成才能下一步 |
| 2 確認資料 | 從 MMA Kids 自動帶入姓名、生日、手機、地址、職業、開戶目的 |
| 3 帳戶設定 | MMA Kids 的錢：全部轉進 DAWHO（夢想基金變「夢想存錢筒」）或夢想基金領出；是否讓爸媽繼續看到夢想進度；網銀代號密碼與生物辨識 |
| 4 同意條款 | 約定條款＋「帳戶只能自己用，借人可能變詐騙共犯」→ 簡訊驗證送出 |
| 5 審核 | 約 1–3 個工作天；示範按鈕「審核通過」 |
| 6 完成 | 餘額轉入、夢想存錢筒、信託 $50,000、學堂成果；爸媽的親子分頁結束 |

家長端總覽改為「小安 18 歲了」：申請進度（開始申請 → 身分與資料 → 送出審核 → 開戶完成）、開戶後的變化（信託撥入、親子分頁結束、零用錢轉帳、消費明細與限額不再顯示），可「傳一句祝福給小安」。

流程為示意：實際開戶文件與條件需向永豐確認（見第 6 節）。

## 2. 數字與流程的修正

| 項目 | 規格書 | Demo | 原因 |
|---|---|---|---|
| 本週配對起始值 | 家長端寫「本週配對保留 $50（已達上限）」 | 起始為 **$0**，付款選「存起來」後才開始累計 | 一開始就達上限的話，「存起來」不會有配對 |
| 達標示範 | 需多週累積 | 「快轉：存到只差一點」：媽媽保留 $550、我存的 $1,150，再存 $50 即達標（預設設定下） | 實際需要好幾個週日 |
| 預計達成日 | 固定寫 12/27 | 依每週儲蓄（零用錢儲蓄份＋每週配對上限）計算「約 N 週後達成」 | 數字隨操作與設定變動時仍前後一致 |
| 配對款 | 「先保留在家長帳戶」 | 一律寫「**圈存**在家長帳戶」 | 依討論決定（方案 A） |
| 提前領出 | 未說明配對款 | 領出的金額依比例**解除對應的配對圈存** | 半途領出就拿不到對應配對 |
| 詐騙情境的年齡 | 未指定年齡 | 建議示範前用「示範 ▾ › 16 歲」切換 | 16–17 歲是青少年受騙主要族群；同時示範查看程度變為每月總額時，防詐警示仍即時通知 |
| 家長不同意時的留言 | 一句通用留言 | 依類型：提前領出「先存到目標再說喔！」、大額消費「我們先一起討論看看」、新收款人「這個買家怪怪的，先不要轉」 | 讓情境更合理 |

## 5. 擱置中的議題

- **付款時「存起來」可能被拿來刷配對**：目前照規格書，付款時選「存起來」會觸發配對（每週上限限制成本）。是否改為「只配對實際存入夢想的錢」或「每天最多配對 N 次」，待組內討論。
- **用刷卡回饋配對**：可沿用 MMA 兒童帳戶既有的「父母回饋金自動轉存」機制，待討論。
- **信託**：照規格書顯示 15／18 歲分齡給付；頁面標示「信託商品條件需向永豐確認」。
- **各項設定的自訂範圍**（見第 0 節表格）為 Demo 暫定值，待組內確認。
- **每月上限何時歸零**：Demo 不模擬跨月；正式版應於每月 1 日歸零（或依家長設定的結算日）。
- **18 歲開戶文件**：身分證、第二證件、自拍比對為一般線上開戶做法，實際以永豐公告為準。
