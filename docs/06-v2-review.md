## 1. 可疑刷卡 $3,000 ＋ 家長即時通知

**概念**：異常交易時家長在 DAWHO 即時收到通知，符合親子分頁定位，值得保留。

**情境上的問題**

- 小安「可以用的錢」只有 $320，不可能刷出 $3,000。
- 原規格已會在交易前擋下：單筆 ≥ $1,000 需家長同意、單日消費上限 $1,500、封鎖類別含「境外網購（可選）」（見 `04-mma-kids-spec.md` 第 104–105、405 行）。
- V2 呈現為「先被刷走、事後才通知」，反而顯得產品防不住。

**建議改寫**：陌生海外商店 $3,000 → 因超過門檻／境外類別被系統先暫停 → 媽媽在 DAWHO 選「是小安本人（同意）」或「不是（拒絕並聯絡銀行）」。更能凸顯 MMA Kids 的事前防護價值。

**程式上的問題**

- 交易標記為 `when:'剛剛'`，但孩子端收支紀錄只顯示「今天／週一／上週」（`app.js` 第 602 行附近），孩子看不到這筆，家長端「最近消費」卻看得到。
- 沒有扣餘額、沒有加本週已花，數字前後不一致。
- 家長按「不是本人」後，交易仍留在紀錄中，沒有標示為爭議／退回。
- 說明寫「孩子端會跳出警示」，實際只是一則約 3.4 秒的 toast。
- 孩子付款頁直接放了「⚠ 可疑刷卡」按鈕，把示範用控制混進 App 畫面；示範控制台「防詐」章節也加了同一情境，保留控制台那顆即可。
- 用 `a.title.includes('可疑刷卡')` 判斷警示類型較脆弱，建議改用獨立的 `kind`（例如 `'card'`）。

## 2. 分享罐點擊說明

- 「預留分享金，不會自動捐款，可以和爸媽討論」的說法清楚，風險低。
- 小建議：目前整句放在 toast 中，約 3 秒即消失，改成小卡片或彈窗較好閱讀。
- 錢包 › 預算設定的分享罐說明文字、`05-demo-notes.md` 分享罐描述也一併更新，可一起收。

## 3. 說明中沒提到的其他修改

- **三罐子預設比例 20/70/10 → 50/40/10**：會改變夢想基金預估達成週數與 Demo 講稿數字，需團隊決定。
- **ETA 算法修正（建議收）**：原寫法不論孩子存多少，都把配對每週上限 $50 當成必定入帳；V2 改為 `min(孩子儲蓄 × 配對比例, 每週上限, 夢想剩餘上限)`，較正確。
- **每週預算進度條加零預算防呆**：目前預算選項皆 > 0，實務上不會觸發，但無害。
- **README 被大幅刪減**：線上 Demo 連結、核心想法、功能總覽、文件表、專案結構都被拿掉 → 保留原版。
- **根目錄 index.html 移除 meta refresh 自動導向**：GitHub Pages 首頁不會自動進入 demo → 保留原版。
