# MMA Kids｜人生第一個帳戶

> **永豐 MMA 兒童帳戶的延伸：孩子用 MMA Kids App 管理自己的錢，家長在 DAWHO App 的「親子」分頁陪伴與管理。**
>
> 存起來，媽媽陪你存；完成任務，爸媽送你禮物。

### 👉 [線上 Demo：點這裡直接在瀏覽器操作](https://yui000130.github.io/SinoPac/demo/)

不用下載、不用安裝，打開就能用（電腦、手機都可以）。

⚠️ 本專案為學生提案的概念展示，**並非永豐銀行正式產品**。人物、金額、合作條件皆為示意。

---

## 核心想法

用「教孩子理財」替永豐吸引下一代客戶：

1. **孩子學會理財**：日常錢包管零用錢、付款前想一想、為夢想存錢、完成任務、在學堂學防詐
2. **父母放心又有感**：在 DAWHO 親子分頁撥零用錢、設定配對、出任務、管理安全
3. **永豐得到客戶**：活化 MMA 兒童帳戶、提高父母黏著，孩子 18 歲升級成 DAWHO

## 功能總覽

| 孩子端｜MMA Kids App | 家長端｜DAWHO › 親子 |
|---|---|
| **初次設定**：小安分配三罐子（儲蓄／需要／想要）比例 | **初次設定**：零用錢金額與時間、配對比例與上限、防亂花錢設定 |
| **首頁**：大圓餅圖（我的錢怎麼分／這週花在哪）、可以用的錢、這個月還能花、夢想與任務小卡、安全按鈕 | **總覽**：需要你處理（防詐警示永遠第一、同意請求）、小安這週、消費（依查看程度）、信託 |
| **付款**：付款碼、「可疑詐騙？通知爸媽」（鎖住付款碼）、超過上限送爸媽同意、買下去 vs 存起來 | **零用錢**：選填、可暫停；家人名單 |
| **夢想**：夢想基金＝我存的＋媽媽保留的配對（圈存在家長帳戶，達標才撥入） | **配對**：自選比例與上限，可暫停 |
| **任務**：非金錢禮物，家長按「已完成」才算數 | **任務**：出題、選禮物、看回報、按完成 |
| **學堂**：聰明消費、存錢、防詐課程（答對後「完成課程」）、防詐情境演練，可連動任務 | **安全**：查看程度、防亂花錢設定（每月上限＋單筆上限，可自訂；超過要家長同意）、需要我同意、封鎖類別、永豐防詐守護 |
| **錢包**：收支紀錄（載具自動記帳＋手動補記、補標需要／想要）、每週回顧 | **信託**：從總覽進入 |
| **安全**：遇到可疑的事、幫我看看 | **18 歲**：查看小安申請 DAWHO 的進度，開戶後親子分頁結束 |
| **18 歲**：線上申請 DAWHO（確認身分 → 確認資料 → 帳戶設定 → 同意條款 → 審核） | |

兩個核心機制分開：**夢想基金＝錢**（孩子存的＋家長配對）；**任務＝禮物**（非金錢承諾，不經過帳戶）。

## 互動 Demo

**線上版：https://yui000130.github.io/SinoPac/demo/**

`demo/` 是單一網頁（HTML＋CSS＋JavaScript），不需要安裝或後端。

- 畫面只有兩支手機：左邊是**孩子端**（小安的 MMA Kids App），右邊是**家長端**（媽媽的 DAWHO › 親子），兩邊即時連動
- 打開後先走**初次設定**：媽媽設定零用錢與上限 → 小安分配三罐子
- 用手機下方的分頁切換功能；孩子端按「出示付款碼」後，可點選店家模擬掃碼付款
- 兩支手機上方各有「**示範 ▾**」選單（非產品畫面）：外婆紅包、跑步鞋 $1,200、夢想快轉與週日結算、切換年齡、跳到 18 歲；防詐情境、盜刷、24 小時未回覆、重新設定
- 會依視窗大小等比縮放，電腦、投影、手機都能完整顯示
- 也可以下載後直接用瀏覽器打開 `demo/index.html`
